# Запуск задач

Панель в проводнике Cursor: кнопки и подменю для запуска программы, команды редактора или базы 1С.

Автор: ASMont. Идентификатор: `ASMont.runtask`.

Установка: **Install from VSIX...**, затем **Developer: Reload Window**. Пакет не содержит список кнопок. У каждого проекта свой файл `RunTask/task-menu.json`. На новом компьютере список пуст.

Пароль `/P` и код `/UC` хранятся в секретах Cursor. В `task-menu.json` остается ссылка `secretId`.

Подробности: `Описание.md` и `Инструкция.md`.
