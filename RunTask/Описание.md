# Запуск задач

Расширение Cursor. В проводнике показывает панель "Запуск задач": дерево кнопок и подменю. Щелчок по кнопке запускает программу, команду редактора или базу 1С.

Идентификатор расширения: `ASMont.runtask`, версия `0.2.1`. Автор: ASMont. В интерфейсе панель называется "Запуск задач".

Панель не вызывает другие расширения. Код ставится в Cursor один раз, файлом `.vsix`. Список кнопок в пакет не входит. У каждого проекта свой файл `RunTask/task-menu.json` в папке этого проекта. Другой проект и другой компьютер этот файл не читают. На новом компьютере список пуст, пока в проект не добавлена первая кнопка. Эта кнопка создает папку `RunTask` и файл списка.

## Файлы расширения

Эти файлы входят в пакет `.vsix`:

| Файл | Назначение |
| --- | --- |
| `package.json` | Имя, версия, автор, команды и вид панели |
| `extension.js` | Дерево, мастер кнопок, запуск, смена темы |
| `onec-keys.js` | Ключи запуска 1С и разбор командной строки |
| `Описание.md` | Этот файл |
| `Инструкция.md` | Установка и работа с панелью |
| `README.md` | Текст страницы расширения в Cursor |
| `История.md` | Журнал версий расширения |

## Файл списка проекта

`RunTask/task-menu.json` лежит в открытом проекте и в пакет не входит. Корень файла - объект с полями `title`, `files` и `entries`.

`title` - заголовок панели. `files` - файлы, которые группа "Файлы расширения" открывает по щелчку. Путь в `files` считается от папки `RunTask` этого проекта. `entries` - кнопки и подменю. У подменю есть массив `items`. У кнопки есть либо `run` (программа или база 1С), либо `command` (идентификатор команды редактора).

Пароль `/P` и код доступа `/UC` записываются в хранилище секретов Cursor (`ExtensionContext.secrets`). В `task-menu.json` у такого ключа остается поле `secretId`, без значения. В подсказке дерева значение не показывается. Если в файле еще есть открытый текст, расширение при активации переносит его в хранилище и удаляет из `args`, `keys.value`, `hint` и `tooltip`.
