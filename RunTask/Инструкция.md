# Инструкция

## Установка на другой компьютер

1. Скопируйте файл `ASMont.runtask-0.2.1.vsix`.
2. В Cursor откройте панель расширений. В меню `...` выберите **Install from VSIX...** и укажите этот файл.
3. Выполните **Developer: Reload Window**.

Пакет содержит код панели и не содержит `task-menu.json`. После установки список задач пуст. Кнопки этого проекта на новый компьютер не переносятся.

На компьютере, где расширение уже открыто из папки `RunTask` через связь каталогов, ставить тот же `.vsix` не нужно: получится вторая копия.

## Список проекта

Панель видна в проводнике открытой папки. Она читает только `<папка проекта>\RunTask\task-menu.json`.

Пока файла нет, дерево пустое. Первая кнопка или первое подменю создает папку `RunTask` и файл списка. Отмена мастера файл не создает.

Смена `task-menu.json` на диске обновляет дерево без перезагрузки окна. Смена кода расширения требует **Developer: Reload Window**.

## Запуск

Щелчок по кнопке запускает ее. Подменю только раскрывается.

В аргументах программы `${workspaceFolder}` заменяется на путь открытой папки, `${workspaceFolderBasename}` - на имя этой папки.

Кнопка с командой `projectTaskMenu.cycleTheme` переключает цветовые темы по кругу. Идентификатор темы записывается в настройки открытого проекта, автоопределение схемы Windows для этого окна отключается. Имя темы на несколько секунд появляется в строке состояния.

## Пароль и код доступа

Ключи `/P` и `/UC` мастер спрашивает отдельно. Поле ввода скрывает символы. Значение записывается в хранилище секретов Cursor текущей учетной записи Windows. В `task-menu.json` у ключа остается `secretId`. Подсказка дерева значение не показывает.

После обновления до версии 0.2.1 откройте окно командой **Developer: Reload Window**. Расширение перенесет открытые значения из `task-menu.json` в хранилище и удалит их из файла.

На другом компьютере и у другой учетной записи Windows секрет недоступен. Измените кнопку и введите значение снова. Пока такого значения нет, запуск этой кнопки останавливается с сообщением.

Пока процесс 1С запущен, пароль есть в командной строке этого процесса. Это свойство ключа `/P`.

## Кнопки заголовка

- "Добавить кнопку задачи"
- "Добавить подменю задач"
- "Перезапустить расширение"

На строке кнопки или подменю: изменить и удалить. Внутри подменю можно добавить вложенную кнопку или вложенное подменю. У подменю значок `list-tree`. Значок `play` у подменю при сохранении заменяется на `list-tree`.

## Новая кнопка

Мастер сначала спрашивает тип.

**Запуск 1С.** База берется из списка запуска 1С: `%APPDATA%\1C\1CEStart\ibases.v8i`. Дальше режим, затем ключи. Пробел отмечает ключ, Enter подтверждает выбор. Для ключа со значением мастер спрашивает значение отдельно.

При изменении кнопки те же шаги открываются с текущими значениями: тип, база, режим, отмеченные ключи, значения ключей, дополнительные ключи, название, подсказка и значок. У программы и команды редактора тоже подставляются текущие поля. Enter оставляет значение и открывает следующий шаг. Пустое поле `/P` или `/UC` оставляет сохраненное значение. Если подключения нет в списке баз, оно стоит первым пунктом.

Режимы предприятия и интерактивного конфигуратора: `ENTERPRISE` и `DESIGNER`. Пакетный режим запускает толстый клиент `1cv8.exe`. В одной команде выполняется один пакетный ключ. Для новой пакетной операции заранее отмечены `/DisableStartupDialogs` и `/Out` с журналом `${workspaceFolder}\1c-designer.log`.

Пакетные режимы: выгрузка и загрузка конфигурации в CF (`/DumpCfg`, `/LoadCfg`), выгрузка конфигурации базы данных в CF (`/DumpDBCfg`), выгрузка и загрузка XML (`/DumpConfigToFiles`, `/LoadConfigFromFiles`), обновление конфигурации базы данных (`/UpdateDBCfg`), выгрузка и загрузка информационной базы в DT (`/DumpIB`, `/RestoreIB`), возврат к конфигурации базы данных (`/RollbackCfg`), обновление из файла cf или cfu (`/UpdateCfg`), проверка конфигурации и модулей (`/CheckConfig`, `/CheckModules`), выгрузка и загрузка внешней обработки или отчета в XML.

`/LoadCfg` обновляет основную конфигурацию и не применяет ее к базе данных. Для применения нужен отдельный запуск с `/UpdateDBCfg`.

**Программа.** Команда, аргументы и рабочий каталог. Аргументы в мастере разделяются `;;`.

**Команда редактора.** Идентификатор команды Cursor, например `projectTaskMenu.cycleTheme`.

## Файлы расширения

Группа внизу дерева открывает файлы из поля `files`. Путь задается относительно папки `RunTask` открытого проекта.
